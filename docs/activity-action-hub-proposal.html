Activity Popover: From Jump-List to Action Hub

Critique of the Postplan proposal (fjg5nv39jsa3.postplan.dev) and the interactive demonstration of our upgraded Two-Deck Action-First Popover with inline triage, intent preview, and keyboard control.

State Scenario:
Postplan Spec Summary

The Read-Only Bottleneck

Postplan correctly stripped the noisy secondary message italic preview and introduced pure amber urgency. However, it made the popover a strictly read-only navigation jumper.

1. Context Switch Fatigue

If 4 subagents ask for command execution approvals, Postplan forces 4 window jumps, 4 separate loads, and 4 popover re-openings.

2. Git Diff Stats in Line 3 Waste Space

Displaying atlas/dev +128 -34 in a notification popover doesn't tell the developer why the agent needs attention.

3. The Flat vs. Tiered Dilemma

Variant A (flat) gets chaotic when states mix. Variant B (grouped) wastes 40% of vertical height on dividers and headers.
