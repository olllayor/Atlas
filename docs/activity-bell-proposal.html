What changed

  1. 1.Popover base p-4 no longer compounds with the call site's p-1.5 — internal padding is now a deliberate 6px so rows sit at the right distance from the rounded border.
  2. 2.Tier label is an actual section title: text-secondary at 11px/600, with a 1px hairline rule under it, matching how the rest of the app separates sections.
  3. 3.Mark all read moves out of the header into its own footer row separated by a hairline — no longer competing with the title.
  4. 4.Secondary line is italic + text-faint (one step quieter) so it reads as meta, not content. Title vs subtitle hierarchy is now driven by weight + style + color, not just size.
  5. 5.Row collapses to one line when secondaryLabel is absent — no more phantom whitespace under "which model are u".
  6. 6.Bell badge uses --warning (warm amber/orange across all themes) instead of --accent (blue in default/codex). Reads as "act now" rather than "brand".
  7. 7.Header gets the ⌥⌘A hint on the right, footer repeats it as a soft affordance, so the keyboard shortcut is discoverable both when the list is empty and when it's full.
